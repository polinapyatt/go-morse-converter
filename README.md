# Веб-сервис конвертации Азбуки Морзе (Go)

Финальный учебный проект: веб-сервис, который принимает файлы через HTML-форму, автоматически определяет тип содержимого (обычный текст или код Морзе) и конвертирует его в противоположный формат.

**Автор:** Полина Пятышина  
**Стек:** Go (стандартная библиотека: `net/http`, `html/template`, `io`, `os`, `path/filepath`, `time`)

## Возможности

- Веб-сервер на базе стандартной библиотеки `net/http`.
- Раздача статического HTML-файла с формой для загрузки файла.
- Обработка `multipart/form-data` (загрузка файлов).
- Автоматическое определение типа входных данных (текст или Морзе) без явного указания.
- Конвертация текста в азбуку Морзе и обратно (с поддержкой русского алфавита).
- Сохранение результата конвертации в локальный файл.

## Архитектура проекта

Проект разделен на слои для соблюдения чистой архитектуры:

- **`server`**: создание и настройка HTTP-сервера (таймауты, логгер, роутер).
- **`handlers`**: 
  - `IndexHandler`: отдает HTML-страницу с формой.
  - `UploadHandler`: парсит форму, читает файл, передает данные в сервис и возвращает результат.
- **`service`**: бизнес-логика. Функция автоопределения типа данных (анализ строки на наличие символов Морзе) и вызов конвертера.
- **`pkg/morse`**: предоставленный пакет с логикой перевода (используются функции `ToText` и `ToMorse`).

## Как запустить

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/polinapyatt/go-morse-converter.git
   cd go-morse-converter
   ```
2. Запусти сервер:
   ```bash
   go run main.go
   ```
3. Открой в браузере:
   `http://localhost:8080`

## Как пользоваться

1. На главной странице выбери файл `test` (содержит код Морзе) или `test12` (содержит обычный текст).
2. Нажми «Отправить».
3. Сервис автоматически определит содержимое, конвертирует его и выведет результат на экран. Также рядом с файлом `main.go` появится текстовый файл с результатом конвертации.
